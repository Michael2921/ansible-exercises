This project uses Terraform to provision two EC2 instances: one running Amazon Linux and one running Ubuntu. It then uses 2 separate Ansible playbooks to install and run Jenkins. There are two Ansible playbooks. The first playbook installs the required packages on Amazon Linux, installs Jenkins, and branches to the Ubuntu playbook based on the OS family. If the playbook branches, it uses Ubuntu-specific commands and tools to install required packages, configure the server, add the Jenkins repo and public key, run Jenkins, and confirm the service is up and running.
