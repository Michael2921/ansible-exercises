This project uses Terraform to provision two EC2 instances: one running Amazon Linux and one running Ubuntu. It then uses 2 separate Ansible playbooks to install Docker and deploy a Jenkins container. There are two Ansible playbooks. The first playbook installs Docker on Amazon Linux and branches to the Ubuntu playbook based on the OS family. If the playbook branches, it uses Ubuntu-specific commands and tools to install Docker and run Jenkins on the Ubuntu instance.
